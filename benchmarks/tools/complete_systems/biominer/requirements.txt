# BioMiner main environment (jiaxianyan/BioMiner@17c6161, "BioMiner" in main_environment.yml) for the
# MolScout benchmark: the pipeline client and the MinerU, MolDetV2 and MolGlyph servers. Installed by
# setup.sh with uv into a conda-forge prefix that holds only Python 3.10.14, poppler 24.08.0 (pdftoppm,
# which pdf2image calls for every page image) and openjdk 21.0.6 (java, which py2opsin calls); compute
# nodes have no pdftoppm, and their java is 11. These are main_environment.yml's versions except poppler
# (24.09.0 there, which only Anaconda's own channel has).
#
# Every pin is the version main_environment.yml lists under pip, except these, left out:
# - paddlepaddle-gpu 3.0.0b1 and the nvidia-*-cu11 libraries it brings: MinerU 1.3.1 asks for paddle only
#   in its "lite" extra; the "full" extra installed here runs OCR with the PyTorch port
#   (models/OCR/paddleocr_torch), and BioMiner never imports paddle.
# - tensorrt-cu12/cu13 and nvidia-cuda-runtime-cu13 0.0.0a0 (a placeholder): nothing imports them.
# - the wheels.myhloli.com extra index: it serves MinerU's old detectron2 builds, which 1.3.1 does not use.
# The pip section omits packages the yml takes from conda; the ones the code imports are pinned below
# to the conda versions in the yml (numpy, pandas, PyYAML, requests, scikit-learn, traitlets, ...).
# Not biopandas 0.5.1 (with mmtf-python and looseversion): nothing imports it, and its PyPI release pins
# looseversion 1.1.2 against the yml's 1.3.0.
# Torch 2.6.0 from PyPI is the CUDA 12.4 build; the nvidia-*-cu12 pins are the ones it requires.
# opencv-python and opencv-python-headless both install cv2; setup.sh reinstalls the headless one last
# so that cv2 is one consistent build (ultralytics declares the GUI one).
